# NexOS | Version 1

A lightweight WebOS built with Vite React, Zustand and TailwindCSS

## Features

- Desktop with draggable & resizable windows
- App launcher and a Dock
- Files App with a Filesystem
- Text Editor, Image Viewer, Markdown Previewer
- A Terminal with helpful commands
- Changable wallpaper & desktop icons

## Apps

- Terminal
- Calendar
- Calculator
- Notes
- Text Viewer
- Image Viewer
- Markdown Previewer
- Settings
- Welcome
- Files

## Techstack

- React
- Vite
- Zustand
- TailwindCSS
- Lucide Icons
- Motion

### Core

- window
- desktop
- topbar
- app launcher
- dock

### Functionality

- Stores everything in LocalStorage
- Easy to use, keyboard supported
