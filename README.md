# NexOS

A lightweight WebOS built with Vite React, Zustand and TailwindCSS

## Update

- Added: Browser
- Added: Music Player
- Smaller and floating panel Top Bar
- Fixed Dock size
- Redesigned AppLauncher Search
- Added: Weather
- Topbar now shows Country ISO & Weather temperature

## Features

- Desktop with draggable & resizable windows
- App launcher and a Dock
- Files App with a Filesystem
- Text Editor, Image Viewer, Markdown Previewer
- A Terminal with helpful commands
- Changable wallpaper & desktop icons
